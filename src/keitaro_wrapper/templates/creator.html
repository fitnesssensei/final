Создатель кампании

Гео-поток на Google и поток на оффер создаются одним запросом.

{% if not has_active_offers %}
В справочнике нет активных офферов: создавать кампанию не на что. Обновите кэш или добавьте оффер в Keitaro.
{% endif %}

Гео попадает в фильтр country первого потока; оффер — в default-поток со 100% трафика.

Что произойдёт

  • В Keitaro появится кампания с alias из названия и случайным суффиксом.
  • Поток 1: country = ваше гео → редирект на Google.
  • Поток 2: default → выбранный оффер, доля 100%.
  • После создания откроется редактор этой кампании.

Ключ идемпотентности уже в форме: повторная отправка не создаст дубль.

Значения из .env: домен {{ form.domain_id }}, группа {{ form.group_id }}, источник {{ form.traffic_source_id }}. Если справочник пуст, при первом открытии страницы он читается из Keitaro.
